Løkker: Bruk forEach() som standard for arrays. Bruk for når indekser eller break er nødvendig. Asynkron kode: Bruk async/await og try/catch, ikke bland tilfeldig med .then(). DOM: Bruk textContent, createElement og replaceChildren. Unngå innerHTML med uklarert data. Variabler: Bruk const som standard og let når variabelen må tilordnes på nytt. Unngå var. Navngivning: Bruk camelCase og tydelige engelske navn. Innrykk: Bruk 4 mellomrom og semikolon konsekvent. Funksjoner: Maksimalt 10–15 kodesetninger som hovedregel. Ett ansvar per funksjon. Organisering: Følg utdelt MVC-struktur. API-kall i servicelaget, logikk i controllere, UI i views. Feilhåndtering: Vis forståelige feilmeldinger i grensesnittet, ikke bare console.log. Kommentarer: Bruk korte kommentarer og påkrevde separatorer. Ikke forklar selvforklarende kode. Sikkerhet: Valider brukerinput og vis uklarert tekst som tekst, ikke HTML. Git: Jobb i feature branches og gjennomgå endringer før merge til main.
